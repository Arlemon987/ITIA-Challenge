ITIA KNOWLEDGE QUIZ

Contains index.html, style.css, script.js, and questions.json.
Question bank: 23 factual + 7 analytical. Each play selects 10 random questions; answer choices are shuffled.

Local test: run `python -m http.server 8000` in this folder, then visit http://localhost:8000. Do not open index.html directly as file:// because the question bank is fetched as JSON.

Deploy all four files together to any static web host. No database or login is needed.
